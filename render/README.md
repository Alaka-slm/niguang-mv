# 《逆光》MV 制作与检查报告

成片：[../逆光_MV.mp4](../逆光_MV.mp4)（1920×1080 · 30 fps · H.264 · 294.63 s · 原曲音轨 AAC 48 kHz 立体声）

## 制作方式
| 环节 | 做法 |
|---|---|
| 时间线 | `build_timeline.py` 从 `storyboard.md` 解析 54 个镜头与 53 处衔接，生成 `timeline.json`，这是渲染时间的唯一来源 |
| 画面 | `film.html` + `scenes.js`：每张作画在**同一块画布**上按该时刻的镜头视角统一绘制背景、角色和道具（p5.js + p5.brush 蜡笔笔刷）。角色全部由 `character/character.js` 绘制。镜头推拉作用于整张作画，背景与角色同步运动，没有“背景图 + 单独渲染的角色视频”这类分层叠加 |
| 动画节奏 | 每秒作画 12 张，线条随张数抖动；输出 30 fps，镜头运动在 30 fps 下平滑插值。镜头里静止的背景笔触会在同一画布、同一视角下复用；视角变化超过 18% 或画面范围不够时，按新视角重画（共重画 188 次） |
| 转场 | 按分镜：前景扫过 47 处（窗帘、门板、风沙、浪花、光斑、信纸等蜡笔质感物件）、甩镜 6 处（顺着方向移动并带运动拉丝）。都在 T − ½ 拍、遮挡最满时换镜 |
| 歌词 | 读取 `../lyrics.srt`，画在最上层、画面下方（楷体、米白字加深褐描边），不随镜头运动 |
| 编码 | 浏览器 WebCodecs H.264（约 30 Mbps）→ `film.h264` → ffmpeg 无损封装；音频直接复制 `逆光.mp4` 的原音轨，不重新编码 |

渲染统计：8839 帧，作画 3620 张，平均 0.71 s/帧，总时长约 1 小时 45 分钟。

> 说明：分镜预案里写的是 HyperFrames。它需要 Node.js 22，这台电脑没有安装（下载也未经你同意），所以改用同样“时间 → 画面”可复现的自建渲染器。ffmpeg 来自 pip 包 `imageio-ffmpeg` 自带的二进制（ffmpeg 9.0.2），只装在临时 Python 环境里。

## 检查结果（`finalize.py`、`lyric_check.py` → `check_report.json`）
### 规格
1920×1080，30.0 fps，H.264 High，时长 294.63 s（原音轨 294.61 s），音频 AAC 48 kHz 立体声。

### 响度（ffmpeg `ebur128`）
| | 综合响度 | 响度范围 | 真峰值 |
|---|---|---|---|
| 原曲 `逆光.mp4` | −10.3 LUFS | 13.4 LU | −0.6 dBTP |
| 成片 `逆光_MV.mp4` | −10.3 LUFS | 13.4 LU | −0.6 dBTP |

差值 0.0 LU，两者一致。

### 歌词与演唱对齐
- **方法**：ffmpeg 抽出画面下方歌词带的全部 8839 帧，以每句句中的字形为模板，逐帧找出歌词实际出现和消失的帧，与 `lyrics.srt` 对照。
- **结果**：48 句全部检出，每句句中都在显示。大多数句子在 SRT 起点之后的第一帧出现，误差 0–33 ms，也就是 1 帧的量化误差。
- **离群值**：第 9、10、25、26、28 句的自动检测结果有偏差，原因是亮色转场背景干扰了描边识别。我抽出这些起止时刻前后的帧逐一目视核对，歌词都按时出现、按时消失。拼图见 [lyric_frames.png](lyric_frames.png)。
- **与演唱的关系**：`lyrics.srt` 的起点来自 Whisper 对人声的逐字时间戳，也就是演唱本身的时间。另外，我用 ffmpeg 抽出音轨，在人声频段（300–3400 Hz）做了独立的起音检测：与 SRT 起点的差值中位数为 155 ms，最大 ±380 ms。在全混音里，起音检测会被伴奏起伏干扰，这个数值只作为旁证。

## 文件
- `film.html` / `scenes.js`：渲染器与 54 个镜头的场景
- `timeline.json` / `build_timeline.py`：时间线
- `render_server.py`：本地服务（`.claude/launch.json` 里的 `render` 配置，端口 8767）
- `finalize.py` / `lyric_check.py`：封装与检查
- `film.h264`：编码后的视频流（约 1 GB）。成片里已包含同一路流，只有需要重新封装时才用得到；确认成片无误后可以删除
