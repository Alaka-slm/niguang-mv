## 规格落实情况
- **像素版**：在 320×180 的 Canvas 2D 上逐像素绘制，调色板 26 色（含日出过渡色），样图帧实际用到 24 色；所有渐变都用 Bayer 4×4 抖动；×6 整数放大，`imageSmoothingEnabled = false`。动画为 6 fps 共 4 帧，头发、围巾、窗帘、浮尘逐帧换画，不做补间。
- **纸艺版**：共 77 张“纸”（含光束、光斑），天空是一张印着日出渐变的纸；剪纸件带均匀白边，撕纸件带随机毛边、纤维毛刺和投影；底纹为牛皮纸，墙上剪报和飞舞的碎片用旧报纸（只有栏线，没有可读文字）。动画为 10 fps，每次每张纸随机抖动 1–2 px，导出样图时不抖动。
- **蜡笔版**：p5.js 1.11.3 + p5.brush 1.1.4，大面积用 `cpencil` / `charcoal` 排线（`hatch`），天空的金黄渐变由四条色带的排线互相重叠叠出，描线用 `2B` / `charcoal` / `cpencil`；底层是程序生成的米白纸纹，最后再叠一层“纸面凸点”，模拟蜡笔跳笔露出的纸白。

## 本地预览
p5 / p5.brush 已放在 `lib/`，预览不需要联网。
```bash
python serve.py
```
运行后打开 http://localhost:8765/pixel.html （或 paper.html / crayon.html）。在页面控制台执行 `exportPNG()` 可以重新导出 PNG。
